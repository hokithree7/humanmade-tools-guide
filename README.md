# HumanMade Tools：产品标识与出口工作台

HumanMade Tools 为制造商、品牌和出口团队提供一组实用工具，帮助你整理产品与批次资料、准备条码和标签、核对箱规并制作装箱清单。

**[访问 HumanMade Tools](https://humanmade.tools/)** · **[查看全部工具](https://humanmade.tools/tools)** · **[提出建议](https://github.com/hokithree7/humanmade-tools-guide/issues/new/choose)** · **[查看已有反馈](https://github.com/hokithree7/humanmade-tools-guide/issues)**

> 当前网站以中文操作界面为主；面向客户的公开资料页以英文显示系统字段。产品名称、自定义属性和值按填写原文展示。

这个公开仓库用于介绍产品、提供使用指南和收集反馈。网站的应用源码保存在独立私有仓库；本仓库并不表示源码已开源。

## 适合谁使用？

- 工厂或品牌团队：整理产品规格、GTIN、批号、日期与图片。
- 外贸与包装团队：准备条码、标签、箱规和装箱资料。
- 与同事协作的团队：围绕同一产品或指定批次填写与核对。
- 需要向客户展示资料的团队：选择公开范围，分享固定链接。

## 从这里开始

1. 打开[工具目录](https://humanmade.tools/tools)，按当前任务选择工具。大多数基础工具可先体验；需要跨设备保存或协作时登录账户。
2. 在[我的工作台](https://humanmade.tools/workspace)使用邮箱注册或登录，也可选择 Google 登录。邮箱注册按页面提示完成验证；Google 登录是否可用及其访问体验取决于所在网络和服务配置。
3. 在[创建产品与批次](https://humanmade.tools/tools/lot)中，选择新建或导入已有资料，依次填写产品和批次。
4. 保存后可邀请同事继续填写，或选择批次进入条码工具。
5. 检查编号、生成并读取条码；需要打印时制作标签 PDF。
6. 选择产品或单批次范围，预览将公开的资料并确认；复制固定链接供客户查看。

未保存的内容可能因关闭或刷新页面而丢失。重要资料请及时保存到账号；下载的文件也请自行保管。

## 功能与操作步骤

### 1. 创建产品与批次

**入口：** [创建产品与批次](https://humanmade.tools/tools/lot)

把产品资料和多个批次整理在一个条目中，支持已有产品继续登记新批次。

1. 选择新建，或从已保存的产品、常用资料及模板开始。
2. 按提示填写产品名称、型号、类目、GTIN（如已有）等信息；需要时添加自定义属性。
3. 常用属性名与选项、品牌等可以保存和复用；也可以保存产品属性模板。
4. 添加批号、生产日期、到期日期及其他适用的批次资料。
5. 产品图片支持 JPG、PNG、WebP，最多 3 张，原图每张不超过 8 MB；可选择文件、拖入或粘贴截图。上传后会转换为 WebP 并压缩，最长边为 1600 像素。
6. 点击保存；需要继续制作条码时选择批次，点击“保存并下一步生成”。也可在未完成时先保存草稿并邀请同事继续填写。

保存后可以从工作台找到条目、继续修改、邀请成员或管理公开资料。

### 2. 检查 GTIN 和校验位

**入口：** [GTIN 校验](https://humanmade.tools/tools/gtin)

1. 选择检查完整编号，或计算缺少的最后一位校验位。
2. 原样输入数字，保留开头的 `0`。
3. 查看格式或计算结果，再按实际业务要求核对编号。

这里检查数字结构和校验位，**不能确认编号的分配、注册状态、企业归属或使用许可**。

### 3. 生成与读取条码

**入口：** [条码工具](https://humanmade.tools/tools/barcode)

支持 QR Code、EAN-13、UPC-A、Code 128、ITF-14、Data Matrix，以及工具提供的 GS1 DataMatrix 和 GS1-128 场景。

1. 选择条码用途和类型，或者带入账号里已保存的产品与批次。
2. 填写编码内容；GS1 场景可填写 GTIN、批号、日期等支持的字段，并调整可选字段顺序。
3. 生成预览，检查页面中的本机解码结果和字段解释。
4. 下载 SVG 或 PNG；批量处理按页面提示使用 ZIP 导出。
5. 如需把条码附到固定公开页，先带入已保存的产品与批次，再核对并更新对应公开页。

本机解码是预览辅助，不等于实物扫描、打印质量或合规验收。实际投产前请结合所用设备、尺寸和适用标准检查。

### 4. 标签排版与 PDF

**入口：** [标签排版](https://humanmade.tools/tools/label)

1. 选择内部产品、零售商品或外箱等适合用途的模板。
2. 输入条码与标签文字，设置页面、标签尺寸、行列和间距。
3. 需要批量制作时，按页面提供的 CSV 示例填写数据。
4. 核对排版示意，生成并下载整页 PDF。
5. 打印时选择实际大小或 100%，先用普通纸试印并核对。

模板名称用于说明用途，不能作为市场准入或法规符合性的证明。

### 5. 箱规 / CBM 与体积重

**入口：** [箱规计算](https://humanmade.tools/tools/carton)

1. 每种箱型填写长、宽、高、单位、箱数及重量。
2. 有多种箱型时逐行添加。
3. 查看总箱数、体积和重量；需要估算体积重时填写适用系数。
4. 将核对后的箱规用于运输沟通或装箱清单。

体积重是按所填系数的估算，不是承运商报价。此页面数据不自动保存。

### 6. 制作装箱清单

**入口：** [装箱清单](https://humanmade.tools/tools/packing-list)

1. 填写发货、收货和运输等适用信息。
2. 添加箱规、箱号及每箱产品明细、数量和单位。
3. 核对系统根据明细计算的合计、重量和体积。
4. 生成 PDF，或导出 CSV / JSON；登录后也可将资料保存到账户。
5. 发送单据前，结合实际货物和收货方要求再次核对。

### 7. 账户、云端资料与协作

**入口：** [我的工作台](https://humanmade.tools/workspace)

工作台集中查看自己的产品和受邀参与的条目，并显示创建与最近保存信息。

1. 登录后保存产品或装箱清单。
2. 在产品条目中选择“邀请协作”，填写对方的邮箱。
3. 选择整个产品或指定批次，并设置可编辑或仅查看权限。
4. 生成邀请链接，**自行复制并发送**给该邮箱的使用者；对方使用受邀邮箱登录并接受邀请。邀请链接默认 7 天有效。
5. 未完成的资料也可以先保存，供成员继续填写。保存冲突时按页面提示重新核对，避免覆盖其他人的修改。

单批次成员可查看该批次相关的产品背景，但不会看到其他批次。已经导出的文件不受后续权限撤销影响。

### 8. 公开资料页与 EUDAMED

1. 在条目操作中打开“公开资料页”，选择整个产品及全部批次，或仅选择一个批次。
2. 完整预览将公开的图片与已填写字段，确认适合公开后发布。
3. 已发布的同一范围可直接打开或复制固定链接；后续保存资料会更新同一地址。产品整体与各批次是不同公开范围，各有自己的链接。
4. 在生成条码并带入已保存批次后，可将条码和本机读码结果更新到该批次公开页。资料更新后，如果旧条码未重新生成，页面会提示条码可能滞后。
5. 有有效 GTIN 时可按提示选择附上 EUDAMED 官方公开档案。页面会区分企业填写的内容与查询结果，并显示查询编号和时间。

任何持有链接的人都可能查看公开资料。请在确认前检查备注、负责人、图片等已填写内容。官方查询可能不完整或有延迟，**不等于本站认证、合规结论或销售许可**。

### 9. 企业劳动权益自查（交互预览）

**入口：** [企业责任](https://humanmade.tools/responsibility)

这里展示企业资料登记、劳动权益问题、自查、整改和承诺预览的交互方向。**当前页面明确标注为未签署、未发布的预览**，不能视为已完成的签署、认证、独立审计或监督机制。适用要求需结合实际经营地点和情况独立核对。
